# 风格研究

用户给多条视频并要求风格 / 调性 / 指南时使用。

**模型**：选择当前 DSH 目录中支持图片输入（image）的模型。模型能力以实际会话为准；不能看图则提示切换，不改默认模型。

## 流程

1. 每条视频 `bcc_shots`（`frames=true`）。
2. `bcc_read_frames` 抽查各片关键帧，记录镜头语言、剪辑、光色、节奏。
3. 直接写《风格指南》md，每条结论带「视频 + 时间戳」佐证。成品就是 md，不必再 export。

需要查作品背景、导演访谈、摄影技法或外部参考时，按需使用当前 DSH 提供的网页搜索/抓取工具。DSH 0.2.1-rc.2 可在网页搜索设置开启 DeepSeek Search / Fetch API，包拆拆不另存搜索凭据。外部资料标明链接；把资料支持的背景与本片画面观察分别写清楚。无法联网时先完成视频本身的风格分析。

多条视频的独立探测和读帧可以使用 DSH 并行工具调度。写同一个项目、改切镜和导出时按顺序执行。PTC 模式通过宿主生成的 SDK 调用工具；不用把 bcc 工具名作为直接调用发出，图片由宿主附加到模型上下文。

建议结构：整体印象、镜头语言、剪辑、光线色彩、声音（仅画面可推断部分）、叙事、可复用配方。
