# 拆剧本（看图，必须看完全片）

用户要「拆剧本 / 台词 / 对白」时使用。当前模型是看图的 Vision，**听不到对白**。

**推荐模型**：`deepseek-v4-flash-vision-exp`。不能看图就停下来让用户切换。不要改默认模型。

## 为什么容易漏故事

- 只看「每镜一张切点图」会丢掉长镜头里后半段的情节。
- 只读前 1–2 批（几张图）就写完整剧本，后面几分钟等于没看。

所以拆剧本**禁止**用切点图当唯一输入。必须：`bcc_shots` → `bcc_sample_script`（镜内加密集采样）→ `bcc_read_frames source=script` **循环到 remaining=0**。

## 质量铁律（违反即不合格）

1. **完整性 > 文采**：每个能看见的场景、动作、字幕都不能漏；宁可朴素，不可概括成「众人交谈」。
2. **时间轴连续**：从 `00:00` 写到片尾；场景头时间戳递增、无大缺口。
3. **体量**：大约 **1 分钟 ≥ 300 字**（含画面与可见字幕）。10 分钟片至少约 3000 字。明显偏短 = 漏看，必须补。
4. **不编造台词**：画面没有字幕就写 `【画面未见对白】`，不要脑补对白。
5. **看完再交**：`bcc_read_frames` 返回 `remaining > 0` 时，禁止 `bcc_export`，禁止对用户说「剧本写完了」。

## 必须按这个顺序

### 1. 切镜

`bcc_probe` + `bcc_shots`（`frames=true`）拿到镜头边界和时长。

### 2. 加密集采样（拆剧本专用）

`bcc_sample_script`。它会在**每个镜头内部**按约 1.5 秒抽多张（长镜头有头/中/尾），不是每镜一张。记下返回的 `sampleCount` 和 `next.batches`。

### 3. 分批看完（核心，防漏）

从 `from=1` 开始循环：

```
bcc_read_frames  projectId=…  source=script  from=<下一批>  count=6
```

每批规则：

- 先读每张图上的时间戳（工具会在图前写出 `[HH:MM:SS]`）。
- **立刻把这一段时间写进 `剧本.md`**（追加，不要把前面已写的场景删掉重来）。
- 看返回的 `coverage.remaining` / `nextFrom`。
- `remaining > 0` → 马上用 `from=nextFrom` 再调，禁止跳号，禁止「先写个大纲以后再补」。
- 只有 `remaining=0` 才进入自查。

可选：`bcc_master shanzhiyin --kind script` 只当思维框架，忽略其中的问答流程。

### 4. 自查（不过就补看）

`bcc_script_coverage --from 剧本.md --projectId …`

- `complete=false`：按 `gaps[]` 把对应时间的采样帧再 `bcc_read_frames`，把缺的场景补进 md，再跑一遍 coverage。
- `complete=true` 才允许导出。

### 5. 导出

`bcc_export` kind=`script`。

## 剧本 md 格式

```
[00:00] 1-1 办公室 日/内
△ 镜头从电脑摇到主角，他皱眉点开邮件
【字幕】方案被退回
张三：这个方案怎么又被退了？

[00:15] 1-2 会议室 日/内
△ 投影仪亮起
【画面未见对白】
```

- 场景头：`[HH:MM:SS]` 或 `[MM:SS]` + 编号 + 地点 + 日夜/内外
- `△` = 画面（谁、在哪、做什么、镜头怎么动）
- 看见的字幕用 `【字幕…】`；人名台词一行一句
- 编号 `1-1` 递增
